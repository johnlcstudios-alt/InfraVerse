InfraVerse / NEXUS

Five digital twins — parking, water, conveyor, cold storage and solar power — plus an integrated campus scenario where energy, water, production, cold chain and logistics actually affect each other.

  • Three.js scenes hosted in Edge WebView2
  • Per-user JSON persistence, alarms, analytics and CSV export

About

JohnLC Studios Open Source Softwares

This organization is the public, open source arm of JohnLC Studios, based in Eastern Samar, Philippines. It hosts the alternative GitHub identity where studio projects are published openly instead of being kept in private repositories.

The work spans Windows desktop applications, browser-based 3D simulation, and scripting and automation tooling. Repositories include forks of the studio's attendance and payroll systems for ACLC College Tacloban, kept public for reference and reuse.

Everything listed here is readable and forkable on GitHub. For studio work outside the open source collection, see the main JohnLC Studios website.
